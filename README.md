## 🚀 Getting Started

### Prerequisites
Make sure you have [Python 3.x](https://www.python.org/downloads/) installed on your machine.

### Clone the Repository
```bash
git clone https://github.com/aditya-puri90/Let-s_practice_Python.git
cd Let-s_practice_Python
```

### Running a Program
Run any script using the python interpreter:
```bash
python Basic/01_user_profile_greeting.py
python Control_Flow_loops/01_positive_negative_or_zero.py
python Strings/01_first_and_last_character.py
```
